## Selected state and ordering

Constructor initializes count 0, dwell 5 seconds, default Grow 1 second and copyright 3 seconds, two elapsed clocks, caption flags and original random/deck state. Installed initialization reads viewport dimensions, selects installed layout resources with missing-specific fallback, chooses the large/small export from original command-line flag results, and binds the selected native controls. Large mode obtains caption/effect pairs, reads the first caption Grow duration into +254, retains copyright/load_FX controls, calls the original LoadingText reader and starts copyright timing. Small mode binds 06EB4140/41. Logo replacement occurs only after actual image lookup returns a resource. Full suffix/table, locale/group selection, text parser and virtual property readers remain their own producer contracts.

Advance takes an object in ECX and two physical stack DWORDs, stores the callback pair, increments count, updates clip and (outside small mode) milestone, then handles copyright/dwell admission and effect timer. Strict copyright elapsed > 3 or dwell elapsed > 5 is sampled on an advance. Time alone does not invoke an advance. The native callback/timer path differs from OpenTS3's mapping of completed boot fraction into nineteen steps. Progress clip converts the count as unsigned32 (signed FILD plus 2^32 on negative), multiplies stored binary32 1/19 and installed fill width, adds left and stores clip-right. No native clamp exists; multiplication/addition use x87 intermediate precision before the binary32 store.

Start-caption refills an empty remaining deck, selects through the original RNG helper, erases the selected 16 byte row, sets text, auto-sizes false, starts from viewport right, configures rounded centered incoming/outgoing Grow and uses the first duration for both effects. This establishes selected/removal ordering; it does not prove Random.Shared sequence, seed or distribution. Physical rectangle instructions govern over decompiler scratch expressions. Settle bakes final geometry, resets/stops Grow, hides the visible old line and swaps text/effect pointers. The 10003 event caller, not Settle itself, restarts dwell.

Milestone selects recursive child 06EB410F+count below 06EB4123, obtains duration and shows it while restarting the timed-effect clock. A missing child's decompiler uninitialized temporary is not an invented constant return. Callback-post physically loads event low/high into EAX/EDX and CL=32 before the shift helper, then emits event 10064; decompiler helper argument order is not ABI evidence. Dispatch handles caption 10003, tick 0xC and completion 10064. Tick posts after active effect elapsed-duration >= 1/65536 then clears timer. Completion forwards payload through the original global interface +124 and returns AL=1. Other events delegate ordinary window dispatch.
