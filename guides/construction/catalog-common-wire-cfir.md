# Catalog common wire and CFIR consumer closure

Original PC1.67 static instruction evidence, with complete native function boundaries and actual annotated Ghidra C. No target execution, compiled tests or writer round-trip is claimed.

Hashes both CBF29CE484222325; price/crap/icon/environment/priority/product-name-hash0, steal/repossess true, roof/world flags false. Status64 is not stored here and every valid wire reads it. ## Common advancement

Read UInt32 version. Version>=10 reads two UInt64 hashes before text. Read two raw strings, price/niceness/crap DWORDs, status byte; versions<5 OR0x10 if mask0x02 is set, otherwise OR0x20. Versions<6 read obsolete subsort string. Versions<9 read icon TGI16, otherwise UInt64 icon. Read unused byte; versions>=3 environmentDWORD,>=7 fireDWORD,>=8 stealbyte,>=11 repossessbyte,>=12 priorityDWORD. Versions4..9 read hashes16 here. Versions>=13 roofbyte,>=14 worldbyte,>=15 product-nameDWORD. No upper version whitelist. Absent fields retain proved constructor defaults. Boolean bytes normalize nonzero via [ASM](../../evidence/native/functions/004DD860_Stream_ReadBoolean.asm) ([annotated C](../../evidence/native/functions/004DD860_Stream_ReadBoolean.c)). Scalars/TGI are little endian; string code units use the opposite flag.

## Three actual runtime consumers and bounded correction

One shared CFIR decoder must serve parts, construction-list common metadata and CFIR icon selection. A parts-only correction would leave old CFIR versions rejected by list admission or icon decoding. The host reads a private payload remainder; its logical common cursor remains after the header while a nonzero-extent table is read at signed32(unchecked(saved+offset−4)). Extent0 does not seek; offset0 still rejects. Extent is not a strict table-size cap. Under2 reads seven inline full keys; >=2 rejects invalid ordinals and preserves valid zero keys. Host bounds/errors differ from unsafe native arithmetic/status. Width remains byte→int0..255.

No runtime CFIR writer was found; C95380 is QueryInterface, not a writer. Shipped external wrapper serialization does not establish original old-version writer behavior. Cache/stamp/masking/error ownership, non-CFIR decoders and tool/planner policy remain separate. No original managed-package duplicate or full native catalog lifecycle is asserted by this bounded native wire proof.
