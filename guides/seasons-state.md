# Original Seasons world state and CPU producers

This guide covers selected original PC1.67 native paths. Function names in the paired exports are analyst-assigned. Instructions establish the static contracts; they do not constitute retail runtime execution. Shader equations are covered separately by the selected original program evidence.

## Tree user data and snow inputs

The [tree field parser](../evidence/native/functions/007C0290_Seasons_ParseTreeUserDataFields.asm) ([annotated pseudocode](../evidence/native/functions/007C0290_Seasons_ParseTreeUserDataFields.c)) lexes a whole semicolon-separated string. It accepts quoted values, removes their surrounding quotes before passing the inside text to numeric readers, and rejects invalid overall syntax. The [template publisher](../evidence/native/functions/00714C20_Seasons_ApplyTreeUserData.asm) ([annotated pseudocode](../evidence/native/functions/00714C20_Seasons_ApplyTreeUserData.c)) applies seasonal fields only after successful parsing. Fall colors require color0 and absent or nonzero luminance0; missing color1 repeats color0. Snow parameters require a nonzero third component.

[Tree shader registration](../evidence/native/functions/00714420_Seasons_RegisterTreeShaderInputs.asm) ([annotated pseudocode](../evidence/native/functions/00714420_Seasons_RegisterTreeShaderInputs.c)) stores the three-component TreeSnowParams handle at manager+0x9C. The [per-tree binder](../evidence/native/functions/0070EC40_Seasons_BindTreeSnowAndTwigInputs.asm) ([annotated pseudocode](../evidence/native/functions/0070EC40_Seasons_BindTreeSnowAndTwigInputs.c)) uses authored template snow endpoints and scale when the template flag admits them. It binds `(pivot, lerp(endpoint0, endpoint1, snow thickness), scale)`. The [snow-thickness setter](../evidence/native/functions/00713410_Seasons_SetTreeSnowThickness.asm) ([annotated pseudocode](../evidence/native/functions/00713410_Seasons_SetTreeSnowThickness.c)) stores the amount at manager+0x1E0. Without authored snow parameters, the [native fallback initializer](../evidence/native/functions/00F83730_Seasons_InitializeTreeSnowFallback.asm) ([annotated pseudocode](../evidence/native/functions/00F83730_Seasons_InitializeTreeSnowFallback.c)) supplies endpoints -0.2 and0.1 with scale4; the binder still interpolates them. This bound dynamic fallback differs from an unbound precompiled shader default.

[Random-factor construction](../evidence/native/functions/0070E340_Seasons_BuildTreeRandomFactors.asm) ([annotated pseudocode](../evidence/native/functions/0070E340_Seasons_BuildTreeRandomFactors.c)) uses a=variation.x*variation.z and b=variation.y*variation.z, normalizing a/b when their sum exceeds1. [Texture variant resolution](../evidence/native/functions/00715150_Seasons_ResolveTreeTextureVariant.asm) ([annotated pseudocode](../evidence/native/functions/00715150_Seasons_ResolveTreeTextureVariant.c)) inserts the seasonal suffix at the first underscore, or the second when DOT occurs before it, and checks the selected resource namespace.

## Leaf density and falling effects

[Leaf-density addition](../evidence/native/functions/00AA8CB0_Seasons_AddLotLeafDensity.asm) ([annotated pseudocode](../evidence/native/functions/00AA8CB0_Seasons_AddLotLeafDensity.c)) updates retained64x64 bytes immediately for each positive drop, adding truncated amount*255 with saturation. [Decay](../evidence/native/functions/00AA96B0_Seasons_DecayLotLeafDensity.asm) ([annotated pseudocode](../evidence/native/functions/00AA96B0_Seasons_DecayLotLeafDensity.c)) decreases those retained bytes for positive amounts; cleared tiles produce messageB77D1D39. A zero amount leaves density unchanged. Texture-upload dirty timing after decay needs the relevant consumer and is not inferred from this body alone.

[Falling-leaf effects](../evidence/native/functions/00D68DA0_Seasons_UpdateFallingLeafEffects.asm) ([annotated pseudocode](../evidence/native/functions/00D68DA0_Seasons_UpdateFallingLeafEffects.c)) require the fall set, loss sufficiently different from0 and1, and the stored renderer interval (file-initial binary32 0x41055555, approximately8.333333015441895 seconds). Tree records with crown data within100 metres roll chance at most1/3. Effect placement and its separate random draw use the field-owned generator.

## Snow point and object state

[Snow exposure](../evidence/native/functions/00B02EA0_Seasons_TestSnowExposure.asm) ([annotated pseudocode](../evidence/native/functions/00B02EA0_Seasons_TestSnowExposure.c)) returns a visibility result and separate allowance flag; streets can reject exposure while retaining snow presence. [Snow presence/depth](../evidence/native/functions/00D6E270_Seasons_QuerySnowPresenceAndDepth.asm) ([annotated pseudocode](../evidence/native/functions/00D6E270_Seasons_QuerySnowPresenceAndDepth.c)) tests thickness magnitude against FLT_EPSILON or frost against0.5, applies exposure, and returns depth=saturate(2*thickness-1)*0.175. At near-zero depth during melting, the [melt predicate](../evidence/native/functions/00D6DCD0_Seasons_IsSnowMeltedAtPoint.asm) ([annotated pseudocode](../evidence/native/functions/00D6DCD0_Seasons_IsSnowMeltedAtPoint.c)) can clear presence using the CPU map at world X/Z divided by512.

[Object snow writes](../evidence/native/functions/0095F810_Seasons_SetObjectSnowDisableSource.asm) ([annotated pseudocode](../evidence/native/functions/0095F810_Seasons_SetObjectSnowDisableSource.c)) select disable bits20000/40000/80000/100000 by source0–3, calling publication when aggregate mask1E0000 changes between empty and nonempty. [Queries](../evidence/native/functions/0095E120_Seasons_TestObjectSnowEnableBits.asm) ([annotated pseudocode](../evidence/native/functions/0095E120_Seasons_TestObjectSnowEnableBits.c)) use the script bit alone or the aggregate mask. [Publication](../evidence/native/functions/0095E690_Seasons_PublishObjectSnowDisableState.asm) ([annotated pseudocode](../evidence/native/functions/0095E690_Seasons_PublishObjectSnowDisableState.c)) sends shader disable state and propagates parent state to slotted children.

[Snow-cover subset admission](../evidence/native/functions/00ABFE40_Seasons_CollectExteriorSnowCoverParts.asm) ([annotated pseudocode](../evidence/native/functions/00ABFE40_Seasons_CollectExteriorSnowCoverParts.c)) uses its own roof query, outdoor-room and ground-height predicates while traversing levels downward. It is distinct from generic eave shelter.

## CPU grid and puddles

The [wrapped sampler](../evidence/native/functions/00D6ADD0_Seasons_SampleWrappedCpuGrid.asm) ([annotated pseudocode](../evidence/native/functions/00D6ADD0_Seasons_SampleWrappedCpuGrid.c)) reduces coordinates by floor, applies the texture size and half-texel shift, reads the compressed4x4 CPU grid, and performs bilinear interpolation. Its copied-grid ABI and x87 casts require instruction interpretation.

[Point puddle admission](../evidence/native/functions/00D6DFF0_Seasons_HasRainPuddleAtPoint.asm) ([annotated pseudocode](../evidence/native/functions/00D6DFF0_Seasons_HasRainPuddleAtPoint.c)) applies sea exclusion where applicable, noise*wetness/255>=0.1, and off-lot normalY>=0.98. [Candidate collection](../evidence/native/functions/00B6E390_Seasons_CollectLotPuddleCandidates.asm) ([annotated pseudocode](../evidence/native/functions/00B6E390_Seasons_CollectLotPuddleCandidates.c)) selects neighboring tile parts around fully-wet qualifying vertices. [Valid per-level sets](../evidence/native/functions/00B6E9E0_Seasons_RebuildValidLotPuddleParts.asm) ([annotated pseudocode](../evidence/native/functions/00B6E9E0_Seasons_RebuildValidLotPuddleParts.c)) additionally require exposure, room admission, upper-level floor patterns or ground flatness.

## Precipitation cells, splashes and attachment orientation

[Cell model construction](../evidence/native/functions/00D664E0_Seasons_CreatePrecipitationCellModels.asm) ([annotated pseudocode](../evidence/native/functions/00D664E0_Seasons_CreatePrecipitationCellModels.c)) chooses authored model keys by precipitation type and creates five instances for snowstorm, one for other nonzero types. [Cell update](../evidence/native/functions/00D66AD0_Seasons_UpdatePrecipitationCells.asm) ([annotated pseudocode](../evidence/native/functions/00D66AD0_Seasons_UpdatePrecipitationCells.c)) clears for the original view/weather conditions, rebuilds a frustum-derived inclusive neighborhood around the eye, keeps up to12 cells, filters layers by terrain height, and advances allocated clocks.

[Ground splash creation](../evidence/native/functions/00D68890_Seasons_SpawnMissingGroundSplashes.asm) ([annotated pseudocode](../evidence/native/functions/00D68890_Seasons_SpawnMissingGroundSplashes.c)) targets truncated clamp(strength*30,0,30), creates at most5 per tick, and selects rain effects for hail landing on floors. [Wrapping](../evidence/native/functions/00D68640_Seasons_WrapAndFilterGroundSplashes.asm) ([annotated pseudocode](../evidence/native/functions/00D68640_Seasons_WrapAndFilterGroundSplashes.c)) moves existing splashes back into the20-metre square, requeries ground and shelter, and retains each effect's hail/rain classification.

[Roof outline transformation](../evidence/native/functions/00BE6CF0_Seasons_TransformRoofOutlineEdge.asm) ([annotated pseudocode](../evidence/native/functions/00BE6CF0_Seasons_TransformRoofOutlineEdge.c)) transforms endpoints through the lot placement and normalizes the direction by horizontalXZ length, retaining slope. Instance advancement along the three-dimensional edge is a separate placement step.

The [variation-word and leaf-metadata contract](vegetation/variation-words-and-leaf-metadata.md) establishes the selected PC CPU lookup, count division, normalization constant and card/mesh stream producers; complete shader consumption remains separate.

The [weather settings and publication contract](weather-settings-and-publication.md) establishes the selected 23-slot conversion, native record, pending copy/dirty flag, semantic equality and later renderer boundary; it also records the leaf NaN admission and exact stored timer bytes.


## Public rain-puddle query and absent-lot continuation

The registered World_HasFloorFeaturesWorldPosImpl [ASM](../evidence/native/functions/00785B00_ScriptCore_World_World_HasFloorFeaturesWorldPosImpl.asm) ([C](../evidence/native/functions/00785B00_ScriptCore_World_World_HasFloorFeaturesWorldPosImpl.c)) selects exactly featureFlags4 and calls the point-query [ASM](../evidence/native/functions/00D6E1A0_FUN_00d6e1a0.asm) ([qualified C](../evidence/native/functions/00D6E1A0_FUN_00d6e1a0.c)). Other flags return lowALfalse. The point helper uses a single aligned point pointer, lowAL Boolean result and plainRET; its inferred local int/float lane casts are decompiler bit aliases, not native conversions.

The world weather pointer at+74 is required. C68940 searches the actual point X/Z with binary32 allowance0.125. A found lot with a room manager converts to local at-floor location then B482C0 with words0/1; nonzeroAX rejects. **No lot is not rejection**: the helper passes null lot, validity=true and assumeWet=false to the existing [puddle predicate ASM](../evidence/native/functions/00D6DFF0_Seasons_HasRainPuddleAtPoint.asm) ([C](../evidence/native/functions/00D6DFF0_Seasons_HasRainPuddleAtPoint.c)), retaining the original weather receiver in ECX.

At D6E014 the null-lot branch reaches the sea test rather than the lot validity reader. D6E0E2 samples actual CPU noise; two separate MULSS combine current projected wetness and binary32 reciprocal255. COMISS/JA rejects ordered values below stored0.1; this edge is not a universal finite clamp. After an admitted noise value, a nonnull lot returns true, while null lot calls C6A9D0 with an output vector and pointX/Z. The reader selects the outputY lane and COMISS/JB rejects ordered less **or unordered** relative to binary32 bits3F7AE148 (approximately0.98). Thus the public predicate has a real off-lot world-terrain continuation. Full C6A9D0 terrain/normal production, world/bounds/manager lifecycle, CPU map loading and every exceptional input remain unexpanded; these instructions do not promise a puddle at every flat point or visible material output.
