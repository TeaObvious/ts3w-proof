# Lot-content height placement and snow geometry predicates

These are reviewed PC1.67 TS3W.exe contracts. Function and variable names in the annotated pseudocode are analyst assigned. Native instruction behavior is established statically; the descriptions do not assert observed retail gameplay.

The lot-content placement chooser evaluates fitting rotations and nine candidate terrain offsets, scores source perimeter heights against the target, and stores the selected float at placement header+0x34. Exact content/lot dimensions and rotation0 do not bypass offset selection. See [00AC3630 ASM](../evidence/native/functions/00AC3630_LotImport_ChooseTerrainPlacement.asm) ([annotated pseudocode](../evidence/native/functions/00AC3630_LotImport_ChooseTerrainPlacement.c)). The import orchestrator dispatches the placement header through the managers: [00ACD610 ASM](../evidence/native/functions/00ACD610_LotImport_ImportManagersAndObjects.asm) ([annotated pseudocode](../evidence/native/functions/00ACD610_LotImport_ImportManagersAndObjects.c)); the floor manager's loader reads the source layer and invokes the height mapper: [00A97780 ASM](../evidence/native/functions/00A97780_LotImport_LoadFloorManager.asm) ([annotated pseudocode](../evidence/native/functions/00A97780_LotImport_LoadFloorManager.c)). For ordinary non-water content, the mapper writes interior target vertices as source height+header offset and preserves the target outer boundary: [00A8BD10 ASM](../evidence/native/functions/00A8BD10_LotImport_ApplyFloorHeightTransform.asm) ([annotated pseudocode](../evidence/native/functions/00A8BD10_LotImport_ApplyFloorHeightTransform.c)). Water placement has additional branches; this ordinary-height contract does not replace them.

The snow-placement blocker predicate obtains actual objects intersecting the tile, excludes the optional ignored ID, requires render-component+8 bit0, then tests product door/gate or secondaryflagbit12: [00AD0C00 ASM](../evidence/native/functions/00AD0C00_Seasons_TileHasSnowBlockingObjects.asm) ([annotated pseudocode](../evidence/native/functions/00AD0C00_Seasons_TileHasSnowBlockingObjects.c)). Its collector requests all four tile parts and enabled footprint-area mask4: [00AC7480 ASM](../evidence/native/functions/00AC7480_LotQuery_CollectObjectsOnTile.asm) ([annotated pseudocode](../evidence/native/functions/00AC7480_LotQuery_CollectObjectsOnTile.c)). The geometric filter transforms each enabled footprint polygon, includes its signed level offset and tests polygon intersection: [00B0E870 ASM](../evidence/native/functions/00B0E870_LotQuery_TestFootprintPolygonIntersection.asm) ([annotated pseudocode](../evidence/native/functions/00B0E870_LotQuery_TestFootprintPolygonIntersection.c)). Object pivot occupancy and product flags alone do not implement this predicate.

Exterior object roof/snow admission selects owners with an enabled footprint component, obtains a component-box polygon and rasterizes its tile parts before updating snow-disable source0: [00ABE060 ASM](../evidence/native/functions/00ABE060_Seasons_UpdateExteriorObjectRoofSnowAdmission.asm) ([annotated pseudocode](../evidence/native/functions/00ABE060_Seasons_UpdateExteriorObjectRoofSnowAdmission.c)). The polygon's four corners come from the object's component bounding box and transform, not from recombining its enabled FTPT area vertices: [00B0EA00 ASM](../evidence/native/functions/00B0EA00_Seasons_GetObjectComponentBoundsPolygon.asm) ([annotated pseudocode](../evidence/native/functions/00B0EA00_Seasons_GetObjectComponentBoundsPolygon.c)); its lot-space conversion is [00B0EC20 ASM](../evidence/native/functions/00B0EC20_Seasons_TransformObjectBoundsIntoLotSpace.asm) ([annotated pseudocode](../evidence/native/functions/00B0EC20_Seasons_TransformObjectBoundsIntoLotSpace.c)). The source component selected through011E9FC4/948880 is also the box read by the registered native Objects_GetBoundingBox row. Component identifiers and ABI artifacts are retained in the pseudocode rather than inventing unsupported concrete types.

The water query selects a root using floor((point-origin)/cellSize) in each axis and indexes the persisted nested root lookup. This lookup determines ownership of shared root edges: [00B5CA90 ASM](../evidence/native/functions/00B5CA90_WaterGeometry_SelectQueryRoot.asm) ([annotated pseudocode](../evidence/native/functions/00B5CA90_WaterGeometry_SelectQueryRoot.c)). Origin and cell sizes are initialized from bounds and subdivisions by [00B611B0 ASM](../evidence/native/functions/00B611B0_FUN_00b611b0.asm) ([annotated pseudocode](../evidence/native/functions/00B611B0_FUN_00b611b0.c)). Looking through every root's closed rectangle does not preserve this ownership at a shared edge.
