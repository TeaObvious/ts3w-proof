# Placement capability and native query boundaries

Static PC1.67 original. Analyst role names; full owned bodies and actual annotated
C are canonical. Selected contracts do not certify every branch in larger parents.

AFC090 is cdecl(nonnullCatalog), plainRET, FULL EAX0/1 from rawDWORD+A4&403F.
NEG/SBB/NEG normalizes the whole return. This original wall/required-edge predicate
is independent from a host renderer/feature supported-profile mask.
C97780 physically reads EAX=[ECX+A0] and RET, no stack parameters. Its actual slot
caller loads ECXproduct; saved thiscall/no-explicit-parameter/UInt32 metadata models
that getter. It does not implement any placement policy itself.

80D4C0 uses ECXslot plus one product pointer, RET4, BooleanAL. Nonnull product and
slot must both lack None bit1; required=product&CFF38 must be nonzero. Cardinal
rotation02000000 must agree; slot must contain all required bits. Upgrade01000000
is outside THIS required mask. No inference that the bit is unused in the whole
executable, in scripts or across all placement paths follows.

945080 walks runtime-enabled primary/supplemental/secondary polygon layers with an
in/out unsigned cursor. requireAll means flags&mask==mask; otherwise any bit.
Expanded primary lookup uses actual unsigned quotient mapping. On success cursor
advances past match and output points to its polygon; on false output stays as was.
Its caller must still perform all subsequent validation.

B450F0 is cdecl(context,optionalFeedback), RET, BooleanAL. Null object or absent
Footprint component returns true. It requests runtime mask5 with requireAll1 and
calls B44CE0 only for selected nonempty polygon vectors. A missing/failed resource
is not proved equivalent to an absent component. No enabled polygons means no
per-area rejection, but later pivot/region/special-state checks can still fail.
Without feedback first failed area can return immediately; with feedback failures
accumulate while remaining selected polygons are visited.

B44CE0 adds signed area level-offset byte to object level. It transforms polygon,
computes bounds and collects quarters append0/inset0 after actual lot/category gates.
Empty current polygon succeeds; positive-offset Air40 above lot top has a selected
early-success exception. Other out-of-range levels do not all succeed. Full support,
region, material and feedback children remain separate from a feature prefilter.

B3B8E0 reads actual current area surface bits and covered parts. Air40 with original
wall403F can addAny20; catalog ceiling bit10 can widen further withDB. Pool, pond,
roof, region and snow conditions are independent branches, not unsupported flags
because a current host omits them. Its complete live evaluator differs from a
static allowed-mask list even when many ordinary products pass both.

B3E910 is cdecl8stackwords, RET, BooleanAL. Slotted candidate requires admitted slot,
optionally performs80D4C0 depending on skip input, excludes self/parent ancestry
and another occupant, and conditionally performs transform/intersection geometry.
It is not a universal slotted success. Full SIMD/intersection/feedback details are
retained, with the selected boundary identified rather than all branches ported.
The host slotted capability prefilter belongs before the separate actual slot checks.

## Join validators, support and diagnostics without collapsing their ownership

The [wall-flag analysis](../construction/wall-flag-placement-and-physical-support.md)
establishes B404B0's local ordered descriptor sets, required B3CD30 modes and
separate prohibited product/stair/cutout/footprint tests. Its diagnostics pointer
changes first-failure versus continued accumulation. Neither that local temporary
set nor B3E910's actual parent/occupant/reference checks establish a persistent
cross-call identity-string/level/held-object cache or its invalidation policy.
Native object/reference acquisition and component state producers must be traced
for each retained query; a source-level supported mask cannot certify them.

The [structural support analysis](../world/lot-structural-support.md) follows
AD2930's exact order: level<=0, AD0040 room/floor, AD22C0 object support with an
excluded Object pointer, ACEC50 partitions, B98530 roof support. It remains distinct
from AD28E0's optional object branch and A8CF20 shell support. Full floorability,
support mask construction, shell/ghost and B0B210 placement-context integration
must still be joined at their actual callers. A room-positive or roof-covered
answer alone cannot substitute for these mechanisms.

[Feedback position](../world/water-brush-response-and-input.md#feedback-position-is-still-a-separate-legacy-owner)
follows AD6720→ADC750→A8C690: the same point carries signed authored level; the
output is a local sampled position. It does not force ground, clear a caller's
previous diagnostic, define candidate retry ordering or establish managed event
world conversion. Follow the opening solver's actual error writer and consumer
before claiming latest-error or clear-on-success semantics. Slot compatibility,
geometry admission, feedback construction and final managed placement veto/commit
have separate outcomes and lifetimes.

The six already canonical owned Listing/C pairs AD2930/AFC020/AD6720/ADC750/
B3E910/B404B0 were reused and their5,232listed instruction bytes compared with the
identified pristine PC1.67 executable. No new database operation, export, mutation,
save, original runtime or complete placement acceptance follows from this join.
