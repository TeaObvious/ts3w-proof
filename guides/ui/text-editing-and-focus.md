## Character/key and selection contracts

Native Character reads one low16 UTF16 value from two incoming DWORD slots. ReadOnly bit1 returns handled=true without editing. Under0x20: Tab and unrecognized controls return false; LF/CR require AcceptsReturn bit2 and CR normalizes toLF. Values>=0x20, including0x7F, proceed. Equal cursor/anchor and Overwrite8 replaces one unit; otherwise replace actual selection. Replacement return is ignored before true. This is not `char.IsControl`, unconditional insertion or a cursor-only editor.

KeyDown has three words/RET0x0C, event1→primary0x30; Character event5→primary0x38 zero-extends the character. Key switch is unsigned key-8<=0xD6,215 bytes mapping to20 target entries. Return tests editor **AcceptsReturn2**, not a modifier: when absent it builds Accept22 with original controlID/full caption length/pointer and returns false. Tab sends its event and false. Escape invokes editor0x90(0) and false. Backspace/Delete consume selection when present; arrows/Home/End/Page keys use native movement units and modifiers. Modifier-gated C/V/X/Y/Z routes clipboard/undo/redo; password/clipboard/read-only/modal state gates remain explicit instructions. There is no demonstrated Ctrl+A branch in this body. Unknown nonalphanumeric defaults can return false. Do not treat all focused keys as natively consumed.

ReplaceSelection uses unsigned min(cursor,anchor), max-min and editor0x8C. ReplaceRange clamps start/removal to current UTF16 length, rejects empty no-op, and rejects only growth beyond maximum; shrinking an already-over-limit string is allowed. It constructs a0x34-byte action containing removed/inserted spans and both old/new cursor/anchor values, applies it before live-caption validation, rolls back and destroys the action on veto, then maintains/free undo state on success. Optional TextChange chooses custom controlID if nonzero else authored, sends full length/text, then event23, flag invalidation and IWindow refresh. Validation bool begins1. Selected full callers establish this chronology; the apply/rollback/history implementation details remain actual separate callees, not inferred complete algorithms. Allocation null is not silently a safe rejection: the original body subsequently dereferences the action.

## Focus and reference contract

Public focus Get first obtains service and handle authority; raw lookup returns an IWindow pointer without acquisition, while the bridge calls virtual0 then translates using kind0x30. Both original bridge entries are physically caller-clean with plain RET; one/two stack DWORDs respectively. Setter zero forwards null; nonzero kind0x30 must resolve and query interface0xEEEE8218. Its saved-ESI branch reloads context from ESP+8, the actual first argument. Service setter receives context then interface, consumes8 bytes and reports booleanAL only.

Service uses10 fixed records with stride0x2C, no incoming context bound check in selected getter/setter. Set rejects invisible targets, rejects disabled except mouse1, checks ancestor admission, may update pending target without actual transfer while capture/pending state applies, drains stored event and publishes before callbacks. It acquires/releases old target, sends event10 and conditional Lost27, then rereads current to honor a reentrant replacement. New event10/Acquire26 proceeds only through that actual continuation. This is richer than a dictionary and unconditional snapshot-ancestor iteration. Native full retirement/reset, descendant routing filters and current bridge grid-edge equivalence remain separate closure questions.
