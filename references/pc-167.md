SSH über Port 22 konnte hängen. Falls derselbe konkrete Fehler erneut auftritt,
war folgender begrenzter Override verwendbar:

    git -c core.sshCommand='ssh -o ControlMaster=no -o ControlPath=none -o Hostname=ssh.github.com -o HostKeyAlias=github.com -o StrictHostKeyChecking=yes -p 443 -o ConnectTimeout=15 -o ServerAliveInterval=10 -o ServerAliveCountMax=2' fetch origin ts3w-proof

Keine Hostkeyprüfung abschalten oder globale Git-/SSH-Konfiguration ungefragt
ersetzen. Tool-/Verbindungsfehler bleiben von Forschungsbefunden getrennt.
