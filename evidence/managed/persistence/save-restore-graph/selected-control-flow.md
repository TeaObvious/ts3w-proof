# Managed save/load control and failure boundaries

The authority is the [identified original ScriptCore resource](../../reference-inputs.json), with [four original MethodDefs, fields, instruction bytes and EH metadata](selected-control-flow.json) and their [complete selected IL transcription](selected-control-flow.il.txt). The descriptions below are annotated interpretations, not rebuilt or original C# source. They preserve the distinction between native object materialization and the managed serializer/VM/task-state machinery.

| Original MethodDef | Inputs and concrete behavior | Failure/ownership boundary |
| --- | --- | --- |
| `060001FB` `ScriptCore.LoadSaveManager.SaveWorld` | An instance Boolean-returning method with no formal inputs. Allocates display class `0600120E`, checks yielding through `0A000061`, creates `Boolean[1]`, stores it in closure field `04000145`, supplies delegate `0600120F` to Native SaveWorld import `060001D5`, then returns array element zero. | No local catch/finally. Native progress, callback timing and successful file persistence are not established by the wrapper. The default false array element is not an explicit completion notification. |
| `0600120F` `ScriptCore.LoadSaveManager+<>c__DisplayClass1.<SaveWorld>b__0` | Instance Void(Boolean), 10 CIL bytes. Loads field `04000145`, index 0 and the supplied Boolean; executes `stelem.i1`; returns. | The callback really writes the captured result array. It neither schedules itself nor proves that Native invokes it. |
| `06000209` `BeginLoadObjects` | Static Void(UInt32,UInt32). Constructs NativePersistReader and stores `sNativeReader` (`04000036`); constructs/stores group PersistReader `mObjectGroupReader` (`04000042`); creates FastStreamReader, calls PersistReader.Load; conditionally finds/stores TaskStateCollection `sTaskStates` (`04000044`). | Its sole Finally covers only the Load region and conditionally disposes FastStreamReader. Reader statics have already been published. A null selected TaskStateCollection does not clear an older static value in this method. |
| `06000216` `EndLoadObjects` | Static Void(). If group reader exists, ExecutePostLoads; if task states exist, dispose then clear; if reader exists, dispose then clear; finally clear native-reader static. | No EH region/finally. A throw from postloads or disposal can prevent later clears. This is normal-path ordering, not unconditional exception recovery. |

The closure's whole executable sequence is `ldarg.0; ldfld 04000145; ldc.i4.0; ldarg.1; stelem.i1; ret`. This establishes a Boolean data dependency, without substituting an opaque pointer for the managed callback protocol.

BeginLoadObjects' EH clause is `Finally`, try offset 28/length 14, handler offset 42/length 10. Its original physical method header and complete extra-section bytes are retained in the JSON. SaveWorld has 51 CIL bytes, its closure 10, BeginLoadObjects 88 and EndLoadObjects 70: 219 total. These are method-local instruction/EH facts; they do not close all allocation, deserialization, task restoration, callback, postload or runtime failure paths.
