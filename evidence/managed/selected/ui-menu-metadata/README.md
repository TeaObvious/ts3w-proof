# Original menu metadata wrappers

Four selected pristine PC1.67 bodies,128 CIL bytes, metadata signatures, full
method headers and empty EH tables. [Members](members.tsv), [packaged identities](identities.json),
[UI IL](ui-metadata.il.txt), [UI projection](ui-metadata.cs.txt),
[ScriptCore IL](scriptcore-metadata.il.txt) and [ScriptCore projection](scriptcore-metadata.cs.txt)
join the [existing native metadata/image guide](../../../../guides/ui/image-request-and-key-derivation.md#menu-metadata-allocated-images-and-issued-source-limits).
These selected members are not additional disjoint coverage beyond earlier broad
UI observations. UI060012BA/12BC and ScriptCore06000EC3/EC5 were selected anew
from original package-extracted assemblies using ILSpy library and metadata;
raw CIL/header bytes were independently checked against their pristine PE RVAs.
No original assembly execution, retargeting or mod binary is used. Package key,
version, MVID and SHA256 distinguish the actual shipped artifacts in identities.

Zero household clears caller image, zero lot/world leaves caller image unchanged.
Native output slots and original managed ref policy are different layers. These
bodies do not implement native provider/image pool/format/GPU lifetime.
