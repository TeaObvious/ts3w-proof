# TS3W PC 1.67 reference

A growing reference for the original The Sims 3 PC 1.67 executable, its managed bindings and behavioral contracts. Research is active; this is not a complete reference release. Static byte/IL findings, current database ownership, understood behavior and actual execution remain separate claims.

The complete earlier proof corpus is now retained here: [API and system overview](references/retained-proof-overview.md), [1,775 registered API pages](api/README.md), and the separate [Create a World reference](caw-proof/README.md). The [snapshot scope](guides/reference/retained-proof-snapshot.md) distinguishes retained exports from maintained successors; the [source path map](indexes/retained-proof-paths.tsv) resolves every old proof path.

Start with the [central reference identity](evidence/reference.json), [coverage inventories](inventory/README.md), or [native evidence index](indexes/native-evidence.tsv).

The [function-name reconciliation index](indexes/retained-function-name-refresh.tsv) records the exact historical symbol differences: 49 genuine retained C sources are reused (36 imported C replacements and 13 unchanged maintained successors), while 1,418 targeted C exports remain open. This is separate from the deferred variable mapping.

The current TS3W index contains 5,117 canonical evidence entries: 5,039 added from the earlier proof plus 78 maintained Research entries. Seventeen overlaps use the maintained successor and do not create duplicate pairs. Two retained entries, 0095F620 and 00C99950, are instruction-qualified windows with comment-only C and no exact current Ghidra definition. This is neither a count of 5,117 complete Ghidra function bodies nor semantic coverage. Existing body-window, annotation, ABI and function-identifier gaps remain explicit; historical C variable mappings are retained until the final overall export from maintained Ghidra. All 1,746 older next-entry/8 KiB exports were audited against their archived artifacts and current Ghidra ownership. The five concrete omitted conditional-path cases are treated explicitly. The [complete stored-range census](inventory/full-body-coverage.md) retains 44,903 ranges and explicitly unassessed remaining executable intervals. The [defined-function census](inventory/native-function-census.md) records 40,854 internal definitions plus 651 external function objects. Most functions and remaining executable regions still need a supported semantic disposition.

[Research rules](rules/index.md) explain scope, evidence, naming, coordination and acceptance. [Repository mapping](references/repositories.md) explains why new findings are published here first. Existing proof material is reused with source commit and path provenance; this repository does not import the old product source tree or its Git history.

Original binaries, packages, assemblies, saves, Ghidra databases and local operating journals are not distributed. Research worktrees and private evidence remain outside the published reference. No original runtime execution is implied by static evidence.
