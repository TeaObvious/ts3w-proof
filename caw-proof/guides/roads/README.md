# Road creation, intersections, rotation, and grading

Five original tool IDs lead into the road editor: `kToolNewRoad`,
`kToolNewIntersection`, `kToolEditRoad`, `kToolRotateRoad`, and
`kToolRoadGrading`. Their managed classes are in the
[tool index](../../TOOL-INDEX.tsv). The named native boundary here is the
original CAW 1.22.10 `Sims3Common.dll`, not the game's PC 1.67 `TS3W.exe`.

## Create and connect

[NewRoadTool](managed/NewRoadTool.cs) submits `CmdCreateRoadSpline` after
collecting spline knots. Its command [calls
`WorldTerrain.CreateRoadSpline`](managed/CmdCreateRoadSpline.cs), with
`isRoadBridge: false`; Undo/Redo toggle the resulting spline's visibility.
The original tool can subsequently submit grouped port-connect and knot
translation commands when joining another road object. The
[WorldTerrain managed class](managed/WorldTerrain-roads.cs.txt) forwards these
requests to its wrapper. The
[WorldTerrain wrapper](managed/WorldTerrainWrap-roads.cs.txt) declares
`WorldTerrainWrap_CreateRoadSpline` and
`WorldTerrainWrap_CreateRoadIntersection` and forwards their returned native
handles to managed wrappers. This establishes the bridge and command ordering,
not the geometry generated by either native constructor.

[CmdCreateRoadIntersection](managed/CmdCreateRoadIntersection.cs) is the
managed intersection constructor/visibility command.
[CmdRotateRoadSquare](managed/CmdRotateRoadSquare.cs) retains the managed
rotation command and its connected-road updates. Native position, angle,
locking, and connection mutations need the corresponding exports and helper
instructions to prove exact behavior.

`CmdCreateRoadIntersection.Execute` returns `true` without checking whether
`CreateRoadIntersection` returned a non-null object. Its command result alone
is therefore not proof that an intersection was created.

## Grade

The [RoadSpline wrapper excerpt](managed/RoadSpline-grading.cs.txt) declares
`RoadSplineWrap_FlattenRoad`, `RoadSplineWrap_FlattenRoadSlope`, and
`RoadSplineWrap_LimitRoadGrade`. Return values are converted to booleans by
testing nonzero. The native terrain raster and road-grade algorithm are not
established by these declarations.

The helper checks a lock byte, adds the delta to its stored rotation and
invokes updates. The intersection constructor ([instructions](../../evidence/native/Sims3Common/functions/10996D50_WorldTerrainWrap_CreateRoadIntersection.asm) ([annotated pseudocode](../../evidence/native/Sims3Common/functions/10996D50_WorldTerrainWrap_CreateRoadIntersection.c)),

are additional entry points; neither establishes the full road geometry or

The intersection export's Ghidra pseudocode infers `void`, while the original
[managed declaration](managed/WorldTerrainWrap-roads.cs.txt) returns `IntPtr`.
Its raw wrapper calls `0x10146ae0` and returns without overwriting `EAX`;
use the managed signature and [raw instructions](../../evidence/native/Sims3Common/functions/10996D50_WorldTerrainWrap_CreateRoadIntersection.asm) ([annotated pseudocode](../../evidence/native/Sims3Common/functions/10996D50_WorldTerrainWrap_CreateRoadIntersection.c))
for the return contract, not the decompiler prototype.
