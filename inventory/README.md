# Coverage inventories

The reference is in active research. None of these inventories establishes semantic completeness or observed runtime coverage.

- [Legacy artifact audit](legacy-window-audit.md): all 1,746 old next-entry/8 KiB windows, with searchable TSV and JSON.
- [Current legacy body metadata](legacy-live-body-audit.md): live ownership for the same entries, kept separate from the artifact audit.
- [Independent pilot selection](pilot-selection-review.md): original-PE byte checks and representative counterexamples.
- [Coverage model](coverage-model.md): separate body, data, binding, semantics, annotation/persistence and runtime dimensions.

The five confirmed omitted-branch cases are now represented by the [fast-field guide](../guides/persistence/fast-field-reading.md) and [thumbnail guide](../guides/rendering/thumbnail-generation-callbacks.md). Their old snapshot audit remains historical; its recorded open questions are not silently rewritten into global closure. Capturing the continuation bytes closes the concrete old ASM omission, while downstream and database-boundary questions remain explicit.

The [native evidence index](../indexes/native-evidence.tsv) resolves the currently adopted canonical pairs. The complete stored-definition/range census is now recorded. Semantic dispositions of functions and remaining code are still in progress. No exclusion follows from an unknown name or missing pair.

- [Defined-function census](native-function-census.md): 40,854 internal definitions and separately identified external locations.
- [Complete stored-range census](full-body-coverage.md): 44,903 ranges, exact mapped-code complement, 1,023 singleton metadata entries and unassessed semantic status.
- [Executable input zones](remaining-code-method.md): independent PE checks and the limits of interpreting stored ownership.

- [Registered capture frontier](native-capture-frontier.md): 1,733 distinct native targets joined to 1,777 bindings, with qualified acquisition priorities and dependency edges.
- [Bounded remaining-region data assertions](remaining-region-dispositions.md): four guarded dispatch-table intervals totaling 118 bytes; baseline regions and all unasserted pieces remain explicit.

- [Retained complete proof corpus](../guides/reference/retained-proof-snapshot.md): the entire earlier proof, 5,037 added TS3W entries, 17 maintained successors, separate CAW/shader/managed evidence and a complete [old-to-current path map](../indexes/retained-proof-paths.tsv).
- [Historical native reuse audit](legacy-reuse.md): searchable 5,054-entry byte/union catalog and bounded 90-entry name-freshness snapshot. Its original audit boundary remains historical; the subsequent corpus import is recorded separately.

- [Bounded required instruction evidence](remaining-instruction-evidence.md): four exact assertions totaling 1,690 complement bytes for two singleton-entry continuations, with 20 parent bytes still unresolved; metadata ownership and the existing data assertions remain unchanged.

- [Unowned indirect-target instruction evidence](remaining-instruction-context-evidence.md): a separate typed 31-byte/eleven-start context assertion for a conditional slot+8 target, with retained NoFunction and 66 parent bytes unresolved; no canonical function pair is added.
